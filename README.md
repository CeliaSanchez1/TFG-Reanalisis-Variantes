# Trabajo de Fin de Grado- Reanotación de variantes genómicas
# Descripción
Este repositorio contiene el pipeline desarrollado para el análisis de variantes genómicas a partir de datos de exoma. El objetivo es la anotación, filtrado e interpretación de variantes SNV, así como la evaluación de cambios en las anotaciones derivados de la actualización de bases de datos.
# Requisitos
